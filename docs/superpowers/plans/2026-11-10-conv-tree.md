# conv-tree Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** conv-tree is a herdr plugin pane. It shows every Claude Code conversation in a project folder as a tree of the user's own prompts. It marks where the focused Claude pane currently is, and lets the user fork from any prompt (or merge a branch's gist into another branch) into a new side pane.

**Architecture:** A pure-Python core reads `~/.claude/projects/<slug>/*.jsonl` and works with it:
- tails each file incrementally
- unions records by `uuid` into one graph
- derives a forest of prompt nodes
- writes fork session files

A thin `Herdr` wrapper shells out to the `herdr` CLI to find panes and sessions, split panes, start Claude, and send text. A Textual app renders the forest, polls once per second, and binds keys to fork and merge. A `herdr-plugin.toml` declares the pane and an "open" action.

**Tech Stack:** Python 3.12, Textual, pytest, uv. External tools are herdr 0.8.0 and Claude Code 2.1.322.

**Spec:** `docs/superpowers/specs/2026-11-10-conv-tree-design.md`

## Global Constraints

- Never modify or delete existing `.jsonl` files. The only files written are new fork session files (spec §3, §8).
- Fork and merge branch only the conversation. No worktrees and no file-history replay. The new pane opens in the same cwd as the source (spec §2 "使われ方").
- Show only real user prompts as nodes. Hide assistant, tool and meta records (spec §6.2).
- Separate (unrelated) trees are listed newest first (spec §6.2).
- "You are here" follows the focused Claude pane whose cwd equals the project cwd. Other Claude panes in that project get a weaker marker. The current marker carries a hint that it is the last *recorded* position (spec §6.3).
- Fork cuts **before** the selected prompt and puts that prompt's text in the new pane's input box unsent. Merge opens A **including** A and its result (spec §6.4, §6.5).
- Merge source B covers the path from the common ancestor (exclusive) to B (inclusive), with results. With no common ancestor, the path covers B's root to B (spec §6.5).
- Merge text is shown in an editable screen before it is sent (spec §6.5).
- Refresh interval is about 1 s, and refresh reads only appended bytes (spec §6.6).
- Platform: Linux, Python 3.12, herdr 0.8.0, Claude Code 2.1.322 (spec §8).

### Facts verified during planning (use these, do not re-derive)
- Project dir slug: `re.sub(r"[^A-Za-z0-9]", "-", cwd)`. For example, `/home/user.name/projects/conv-tree` maps to `-home-user-name-projects-conv-tree`.
- Parent link is `parentUuid`. A `system` record with `subtype == "compact_boundary"` has `parentUuid: null` and `logicalParentUuid: <uuid>`. For tree display, use `parentUuid or logicalParentUuid`.
- Claude's own fork file has these properties:
  - It is the root→leaf path of records, and it starts at the most recent `compact_boundary` on that path, or at the root if there is none.
  - Each record is copied with `sessionId` replaced by the new id. `uuid` and `parentUuid` are kept unchanged.
  - Meta records without a `uuid` may precede the path. They are optional.
- Real prompt test, verified on real data:
  - `type == "user"`, and not `isMeta`, and no `toolUseResult` key, and not `isCompactSummary`, and not `isSidechain`.
  - If the record has a `promptSource` key, it must not be `"system"` (task notifications and loop wakeups are `"system"`; typed input is `"typed"`).
  - If there is no `promptSource` (older versions), the text must not start with `<` (`<command-name>`, `<local-command-…>`, `<task-notification>`), `This session is being continued`, or `[Request interrupted`.
  - `message.content` is either a `str` or a list of blocks. Text is the joined `text` blocks, and each `image` block becomes `[image]`.
- Pane → session: `herdr pane process-info --pane <id>` gives `.result.process_info.foreground_processes[].pid`. Then `~/.claude/sessions/<pid>.json` gives `.sessionId`.
- `herdr agent list` gives `.result.agents[]` with `agent`, `pane_id`, `cwd`, `focused`.
- Plugin manifest (herdr docs, matched against the 0.8.0 binary):
  - top-level `id`, `name`, `version`, `min_herdr_version`, `platforms`
  - `[[panes]]`: `id`, `title`, `placement`, `command` (argv array)
  - `[[actions]]`: `id`, `title`, `contexts`, `command`
  - Injected env: `HERDR_PLUGIN_ROOT`, `HERDR_PLUGIN_STATE_DIR`, `HERDR_PANE_ID`, `HERDR_BIN_PATH`
  - Key binding goes in the user's `~/.config/herdr/config.toml` as `[[keys.command]] type = "plugin_action" command = "conv-tree.open"`.

## Review Focus

1. **A half-written last line** (Claude is mid-append) → it is not parsed or skipped forever. The reader keeps its offset before the partial line and picks it up on the next poll. Pinned in Task 1.
2. **Prompts given as block lists, including images, and slash-command or notification user records** → block lists show their text plus `[image]`. Commands and notifications never appear as nodes. Pinned in Task 2.
3. **Conversation through a compaction** → the tree stays one connected tree across the boundary, and a fork past a boundary starts its file at that boundary. Pinned in Tasks 2 and 4.
4. **No Claude pane focused, a focused Claude in another project, or a missing `sessions/<pid>.json`** → no marker and no crash. Pinned in Task 3.
5. **The same prompt present in several files (fork copies)** → it is one node that lists all its sessions, not duplicated subtrees. Pinned in Task 2.

### Task 2: Conversation graph and prompt forest

**Files:**
- Create: `src/conv_tree/graph.py`, `tests/test_graph.py`

**Interfaces:**
- Consumes: `JsonlTail`, `project_dir` from Task 1.
- Produces:
  - `@dataclass Record`: `uuid: str`, `parent: str | None`, `type: str`, `timestamp: str`, `sessions: set[str]`, `raw: dict` (first copy seen).
  - `is_prompt(raw: dict) -> bool` and `prompt_text(raw: dict) -> str`, following the rules in Global Constraints.
  - `@dataclass PromptNode`: `uuid: str`, `text: str`, `timestamp: str`, `sessions: set[str]`, `parent: "PromptNode | None"`, `children: list["PromptNode"]` (sorted by timestamp ascending).

    - `__init__(project_dir: Path)`
    - `refresh() -> bool`: True if anything changed. It tails every `*.jsonl` in the dir, including new files.

    - `prompt_of(uuid: str) -> PromptNode | None`: the nearest prompt ancestor of any record, itself included.
    - `forest() -> list[PromptNode]`: roots newest first, where a root's age is the max timestamp in its subtree.
    - `path_to_root(uuid: str) -> list[Record]`: root first.
    - `last_result(prompt_uuid: str) -> str`: the text of the latest-timestamp assistant record whose `prompt_of` is that prompt, or `""`.
